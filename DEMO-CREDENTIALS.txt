4. DEPARTMENT ADMIN TERMINAL OTP VERIFICATION WORKFLOW
--------------------------------------------------------------------------------
When a Department Admin signs in or is created:
1. Super Admin creates Department Admin:
   - Credentials card shows Temporary Password AND Confirmation OTP.
   - Terminal immediately prints confirmation OTP banner.
2. Department Admin logs in (http://localhost:5173):
   - Enters email & password.
   - Backend automatically dispatches a 6-digit OTP to the BACKEND TERMINAL.
   - Web console prompts for 6-digit verification code.
   - Enter the 6-digit OTP printed in your backend terminal and click 'Confirm & Log In'.
   - Terminal prints "DEPARTMENT ADMIN OTP VERIFIED & CONFIRMED" and unlocks dashboard.

--------------------------------------------------------------------------------
5. HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------
Terminal 1 (Backend):
   cd apps/backend
   pnpm dev

Terminal 2 (Frontend):
   cd apps/frontend
   npm start
   (Press 'w' to open in browser: http://localhost:5173)

To re-seed demo accounts at any time:
   cd apps/backend
   pnpm db:seed
